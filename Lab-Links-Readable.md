## 📊 Program Overview

This 4-week intensive internship program covers:

| Week | Focus Area | Key Topics |
|------|------------|------------|
| **Week 1** | 🤖 AI Fundamentals | Responsible AI, LLMs, Transformers, Prompt Engineering |
| **Week 2** | ☁️ AWS Core Services | VPC, EC2, S3, Lambda, IAM, Security |
| **Week 3** | 🗄️ Databases & Observability | RDS, DynamoDB, CloudWatch, CloudTrail |
| **Week 4** | 🚀 Capstone Project | Three-Tier Application, IaC, Presentations |

**Total Learning Hours:** ~120-150 hours | **Hands-On Labs:** 40+ | **Projects:** 2 major presentations
