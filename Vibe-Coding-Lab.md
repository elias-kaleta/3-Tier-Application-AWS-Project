# Vibe Coding Lab

## Overview
- This lab activity is designed to allow you to use what you have learned to experiment with vibe-coding using LLMs in an open-ended way.
- The main objective of this lab is to encourage you to make something from scratch with the assistance of an LLM.
- No prior knowledge of programming should be required for this lab.

## Instructions
1. Choose a free LLM to help you vibe code. (ChatGPT, Claude, Gemini, etc.)
2. Create a GitHub repository for your vibe-coded files.
3. Use the LLM to help you make or recreate a browser-based game:
	1. The game must run in a browser.
	2. Simple games will be much easier to make. (e.g. Flappy Bird)
4. Store the game files in the repository for sharing
5. Iterate, add new features, experiment.

## Tips
- The AI can help choose a coding language based on the requirements of your project. Make sure to tell it you want something browser-based.
- If you are unsure what to make, ask the AI for inspiration.
- Push to the repository after changes to the project, it will help you ensure you have backups of your game.
